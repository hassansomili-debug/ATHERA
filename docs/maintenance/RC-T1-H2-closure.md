# RC-T1-H2 — إغلاقٌ رسميّ | formal closure ledger

**الحال: مُغلَق** عند الجيل المُتحقَّق من المستودع.

هذه الوثيقةُ هي **الدفترُ المرجعيّ**. وما خالفها في وثيقةٍ أقدمَ فهو تاريخٌ
لا حالٌ راهنة.

```
الجيلُ المُغلِق : 78288d53b52e92f0df20e5d0cb49851333e6b67f   (main عند الإغلاق)
المخطَّط        : 0037 — سبعةٌ وثلاثون ترحيلًا، ولا 0038
النطاق         : H2-A · H2-B1 · H2-B2 · H2-B3 · H2-B4 · H2-B5 · تبنّي المفتاح في المتصفّح
التالي         : المرحلة ٨ — H2-C + D3
```

## الدعوى العامّة — وحدُّها في النفس الواحد

> **RC-T1-H2 مُغلَقٌ عند الجيل المُتحقَّق من المستودع.** العمليّاتُ المحميّةُ
> الحسّاسةُ لإعادة المحاولة تستعمل أجيالَ تكرارٍ في الخادم مناسبةً لصنفِ
> أثرِها، وغموضُ مزوّدِ النموذج **يُغلَق عليه** بدل أن يُعاد النداءُ أعمى
> داخل الجيل نفسِه، ومعالجةُ الرسالة تستعيد بسياج، والمتصفّحُ يعيد استعمال
> `Idempotency-Key` المعتِم نفسِه للنيّة المدعومة الواحدة داخل حدِّ البقاء
> الآمن.

**وحدُّها فورًا:** الإغلاقُ **هندسيٌّ عند جيلِ مستودعٍ بعينه**. وليس شهادةً
على أنّ كلَّ خدمةٍ منشورةٍ الآن تُشغّل هذا الجيل.

## ما لا يُدَّعى — ولا تُليَّن هذه الجمل

```
exactly-once execution                                   : NOT CLAIMED
exactly-once provider execution                          : NOT CLAIMED
exactly-once physical storage PUT                        : NOT CLAIMED
durable background queue                                 : NOT CLAIMED
automatic crash recovery without a later authorized request : NOT CLAIMED
infinite idempotency retention                           : NOT CLAIMED
cross-tab browser intent identity                        : NOT CLAIMED
cross-device browser intent identity                     : NOT CLAIMED
production-wide certification from repository closure    : NOT CLAIMED
```

ما بُني **تحمُّلُ إعادةٍ آمنة** (retry-safe)، وهو أضعفُ من «مرّةً واحدةً
بالضبط» وأصدقُ منه. وبين إيداعِ الصفّ ووصولِ الجواب نافذةٌ لا تُغلقها قاعدةُ
بيانات.

### H2-B4 — غموضُ مزوّدٍ غيرِ مُثبَتِ المنعة

**والحقائقُ تُقرأ من المصدر لا من الذاكرة.** الحزمتان مُقيَّدتان بمدًى لا
بإصدارٍ واحد: `anthropic>=1.2,<2.0` و`openai>=1.50,<2.0`. فالدعوى **لا
تُعلَّق على رقمِ إصدار** بل على فحصٍ سلوكيٍّ يُجرى على المُثبَّت أيًّا كان
(`test_02`): لا `idempotency_key` في التوقيع، و`_idempotency_header = None`
فلا شيءَ يظهر على السلك. وفي البيئة المُتحقَّقة هنا: `openai 1.109.1`،
`anthropic 1.3.0`.

| البيّنة | الحال |
|---|---|
| تصنيفُ القدرة | `PROVIDER_IDEMPOTENCY_UNPROVEN` للمحوّلَين |
| إعاداتُ الـSDK | `max_retries=0` في كلا المحوّلَين، وفحصٌ ضابطٌ يثبت أنّ الافتراض غيرُه |
| وسمُ العبور | `__athera_external_attempt__` يُودَع في معاملةٍ خاصّةٍ به، و`response_status` يبقى فارغًا فلا يُعاد وسمٌ كجواب |
| موضعُ الحدّ | بعد `gateway.authorize` ومباشرةً قبل `gateway.invoke` |
| الستّةُ المأذونة | `ai/ask` · `brain/ask` · `manuscripts/{id}/sections/{key}/draft` · `projects/{id}/publication-opportunities` · `theses/{id}/opportunities/{oid}/thread` · `profile/import` — لكلٍّ `ModelBoundary` و`before_provider_call` |
| الفحوص | `h2b4_model_ambiguity` — **٥٦** |

**الدعوى بحرفها:** *على الأكثرِ نداءٌ تلقائيٌّ واحدٌ من PUBRIVA لمزوّدٍ غيرِ
مُثبَتِ المنعة لكلِّ جيلٍ مُمفتَح.* ولا تُحوَّل إلى «مرّةً واحدةً بالضبط»:
المزوّدُ قد يكون نفّذ، ونحن لا نعلم.

### H2-B5 — استئنافُ معالجةِ الرسالة وسياجُ عاملها

| البيّنة | الحال |
|---|---|
| المحفّزاتُ الأربعةُ مُسيَّجة | `upload` · `process-file/{id}` · `{id}/reprocess` · منحُ الإذن |
| `ProcessingClaim` جيلًا | `(thesis_id, file_id, attempt, fence, recovered)` |
| تحكيمُ البيات بساعةِ القاعدة | `processing_state_changed_at` بـ`func.now()` |
| الاستعادةُ داخل المحاولة نفسِها | لا محاولةً ثانيةً تُفتعَل |
| `ExtractionRun` ثابت | لا تشغيلةَ ثانيةً للجيل الواحد |
| العاملُ البائتُ يُودِع صفرًا | مُسيَّج |
| حدُّ النموذج على مستوى القسم | دفترُ الأقسام (`section_ledger`) |

**و`BackgroundTasks` تبقى داخلَ العمليّة، وليست طابورًا دائمًا.** موتُ
العمليّة يُنهي المهمّة؛ والاستئنافُ يقع بطلبٍ **مأذونٍ لاحق**، لا تلقائيًّا.

### تبنّي المفتاح في المتصفّح (المرحلة ٦)

| البيّنة | الحال |
|---|---|
| عشرون نمطًا في المتصفّح == عشرون مسارًا مُفتَّحًا في الخادم | مُشتَقٌّ في كلّ تشغيلة، في الاتجاهين |
| فجوةٌ داخل تصنيف H2 المعتمَد | **صفر** |
| النيّةُ نفسُها ⇒ المفتاحُ نفسُه | مغلق |
| نيّةٌ مقصودةٌ جديدة ⇒ مفتاحٌ جديد | مغلق |
| ٤٠١ ثمّ تجديد ⇒ المفتاحُ نفسُه | مغلق |
| `XHR` ⇒ `apiFetch` ⇒ المفتاحُ نفسُه | مغلق |
| نيّةٌ معلَّقةٌ داخل الأفق الآمن | المفتاحُ نفسُه |
| **نيّةٌ معلَّقةٌ تجاوزت الأفق** | **لا مفتاحَ بديل ولا طلبَ يخرج** |
| إعادةُ مدخلِ الرسالة على كائن `File` المحفوظ | مغلق |
| إعادةُ مرفقِ بُبريفا AI على كائن `File` المحفوظ | مغلق |
| توليدُ المفتاح | معمًّى وحدَه — لا `Math.random` |
| المخزن | `sessionStorage` فقط — ولا سجلَّ مفاتيحِ طفرةٍ في `localStorage` |

**والحدُّ تبويبةٌ واحدة.** نيّةُ تبويبةٍ ليست نيّةَ أختها، ولا نيّةَ جهازٍ
آخر. وهذا مقصودٌ لا نقص: مشاركتُها تحتاج قفلًا بين التبويبات لم تُشترَ
فائدتُه بعد.

## حدُّ المستودع وحدُّ الإنتاج

```
إغلاقُ H2 في المستودع   ≠   شهادةُ جيلٍ على الإنتاج
```

الواقعُ المعروفُ الآن، ولا يُعاد كتابتُه:

- دمجُ المرحلة ٦ أحدث **نشرَ Vercel للإنتاج تلقائيًّا** عبر التكامل القائم؛
- **ولم يُطلَق Fly يدويًّا** للمرحلة ٦؛
- ولم يُشغَّل `production-release`؛
- ولم يُشغَّل `production-acceptance`.

فشهادةُ الإنتاج عملٌ منفصلٌ بمشغّلاته، ولا تُشتقّ من هذه الوثيقة.
