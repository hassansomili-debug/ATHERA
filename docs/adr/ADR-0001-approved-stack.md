# ADR-0001 — المكدس التقني المعتمد

- **الحالة:** مقترح (بانتظار الاعتماد)
- **التاريخ:** 2026-08-30
- **المرجع:** PRD/SRS v1.2 §38.6، §31، وتعليمات `CLAUDE_START_HERE.md`
- **يلغي/يُعدّل:** —

## السياق
تحدد الوثيقة المرجعية مكدسًا مزدوجًا مقصودًا: TypeScript/Next.js لتجربة الويب، وPython/FastAPI للخدمات الخلفية والعقل البحثي والتحليل. السبب المعلن (§38.6): الواجهة تتطلب تجربة SaaS تفاعلية عالية الجودة، بينما تعتمد طبقة الذكاء البحثي على منظومة Python الأوسع في الذكاء الاصطناعي ومعالجة الوثائق والتحليل الإحصائي.
تطلب §50 صراحةً توثيق ADR خاص بالمكدس المعتمد، ومنع أي فريق من استبداله في النواة دون قرار معماري معتمد.

## القرار
يُعتمد المكدس التالي، وتُثبَّت إصداراته الدقيقة في `infra/` وملفات القفل:

| الطبقة | التقنية |
|---|---|
| Frontend | Next.js 16+ / TypeScript، RTL/LTR من التصميم الأساسي |
| Backend / API | Python 3.12+ / FastAPI / Pydantic / SQLAlchemy + Alembic |
| AI Orchestration | Python، عبر `ModelProvider` abstraction (ADR-0003) |
| Database | PostgreSQL 16 + pgvector |
| Object Storage | S3-compatible (MinIO في التطوير) |
| Durable Workflow | Temporal |
| Analysis | Python + R في حاويات معزولة |
| Cache/Queue | Redis عند وجود مبرر |
| Deployment | Docker من Sprint 0؛ Kubernetes لاحقًا فقط عند ثبوت حاجة التوسع |

**قاعدة ملزمة:** لا يُستبدل Python/FastAPI أو Next.js/TypeScript في النواة إلا بـADR جديد معتمد يلغي هذا القرار صراحةً.

## البدائل المرفوضة
- **مكدس JavaScript موحّد (Node للخلفية أيضًا):** يبسّط الفريق لكنه يبعد طبقة التحليل الإحصائي ومعالجة الوثائق عن منظومة Python المطلوبة في §18 و§38.6.5. مرفوض.
- **Django بدل FastAPI:** لوحة إدارة جاهزة، لكن دعم async أضعف لسير عمل الأجنتات، والعقود عبر Pydantic أقل مباشرة. مرفوض.
- **Kubernetes من البداية:** يستهلك السبرنتات الأولى في التشغيل قبل وجود مستخدم واحد. مؤجل صراحةً بنص §38.6.7.
- **Neo4j للرسم المعرفي:** §30 تجيز تنفيذ الرسم في PostgreSQL في الإصدار الأول. مؤجل.

## النتائج
- **إيجابًا:** كل طبقة تعمل في منظومتها الطبيعية؛ التحليل وإعادة الإنتاج ممكنان دون جسور هشة.
- **سلبًا:** لغتان ومجموعتا أدوات في مستودع واحد — تُخفَّف بعقد OpenAPI واحد يولّد الأنواع للطرفين، وMakefile موحّد.
- الفريق يحتاج كفاءة في المسارين، وهذا قيد توظيف معلن لا مفاجأة لاحقة.
