# مصفوفة تصنيف البيانات | Data Classification Matrix

المرجع: PRD/SRS v1.2 §36، §32، §47.8 · مطلوبة صراحةً في §50.
الحالة: مقترحة — البند C4 وسقف الإرسال الخارجي ينتظران قرار المستخدم (سؤال 7 في خطة Sprint 0).

التصنيف ليس وسمًا إداريًا: قيمته تُقرأ آليًا في `files.classification` وفي
`ModelRequest.classification`، وتحدد فعليًا ما إذا كان النص يغادر الخادم أصلًا.

| المستوى | المحتوى | التشفير | الاحتفاظ | الإرسال لمزود نموذج خارجي |
|---|---|---|---|---|
| **C0** عام | نصوص منشورة، بيانات ببليوغرافية من OpenAlex/Crossref، أسماء مجلات | قياسي | بلا حد | مسموح |
| **C1** داخلي | مسودات عناوين، ملاحظات عمل، خطط سبرنت | قياسي | حسب المشروع | مسموح — **السقف الافتراضي** |
| **C2** بحثي حساس | مخطوطات غير منشورة، رسائل قبل النشر، فرص بحثية | at rest + وصول مقيّد | مدة المشروع + 5 سنوات | **يحتاج تفعيلًا صريحًا لكل مستأجر** |
| **C3** بيانات بحثية | Datasets غير منشورة، نتائج تحليل قبل الإعلان | at rest + سجل وصول لكل قراءة | حسب Data Management Plan | ممنوع افتراضيًا |
| **C4** بيانات مشاركين | ردود مقابلات، PII، موافقات أخلاقية | PII vault منفصل + تشفير على مستوى الحقل | حسب الموافقة الأخلاقية فقط | **ممنوع دائمًا** — لا يُرفع السقف إليه بإعداد |

## كيف يُفرض هذا في الكود

- `.env` → `MODEL_EXTERNAL_SEND_MAX_CLASSIFICATION=C1` (الأشد تقييدًا افتراضيًا، §36.3).
- `providers/gateway.py::classification_allowed` يرفض أي طلب فوق السقف قبل أي اتصال شبكي.
- `model_runs.max_classification_sent` يسجّل ما أُرسل فعلًا — لا نعتمد على النية.
- قيد `ck_files_classification` يمنع قيمة خارج C0…C4.

## قرار مؤجل

رفع السقف إلى C2 يحتاج، قبل تفعيله: تحديد Hosting region (§47.5)، واتفاقية معالجة بيانات مع المزود، وموافقة مؤسسية موثقة. حتى ذلك الحين تبقى القيمة C1.
