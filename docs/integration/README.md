# طلباتُ التكامل | Integration requests

**لا يملك أيُّ مسارٍ الملفّات العامّة.** `apps/api/athera_api/main.py`، وتسجيلُ
الموجّهات، وسلسلةُ الترحيلات، وقشرةُ التطبيق، والعقودُ المشتركة — كلُّها
للمُكامِل وحده.

ومن احتاج تغييرًا في واحدٍ منها **يقف**، ويكتب طلبه في:

    docs/integration/<track>-requests.md

بصيغة: ما المطلوب، ولماذا، وما الذي يسقط بدونه. ثمّ يمضي في بقيّة عمله.

وسببُ القاعدة أنّ ستّة مسارات تُعدّل `main.py` معًا تُنتج تعارضًا يحلُّه من
لا يعرف نيّة أصحابه — فيُحلّ بحذف سطرٍ يبدو مكرَّرًا، ويسقط موجّهٌ كاملٌ في
صمت. وقد وقع هذا في هذا المستودع من قبل.
